# 俄罗斯方块 —— C 语言项目（AI 辅助完成）

这是一个使用 **C 语言** 编写、并借助 **AI 辅助** 完成的俄罗斯方块控制台游戏。程序完整可运行，包含方块生成、旋转、碰撞检测、消行计分、难度递增和游戏结束判定等逻辑，满足「至少一个能跑起来的 C 语言程序」的作业要求。

## 一、项目信息

| 项目 | 说明 |
|------|------|
| 项目类型 | C 语言控制台程序 |
| 完成方式 | AI 辅助编写，本人调试与验证 |
| 源文件 | `tetris.c`（约 220 行，纯 C，无第三方依赖） |
| 运行环境 | Windows（使用 `conio.h`、`windows.h`） |

## 二、编译与运行

**方式一：MinGW / GCC（推荐）**

```bash
gcc tetris.c -o tetris.exe
tetris.exe
```

**方式二：Dev-C++ / Code::Blocks**

直接用 IDE 打开 `tetris.c`，点击「编译运行」即可。

**方式三：MSVC（Visual Studio 开发者命令提示符）**

```bash
cl /utf-8 tetris.c
tetris.exe
```

> 说明：`/utf-8` 用于防止中文界面乱码。程序无需任何第三方库，编译通过后直接运行。

## 三、玩法说明

| 按键 | 功能 |
|------|------|
| ← → | 左右移动方块 |
| ↑ | 顺时针旋转方块 |
| ↓ | 加速下落一格 |
| 空格 | 直接落到底部 |
| Q | 退出游戏 |

- 共 7 种方块形状（I、O、T、S、Z、J、L），随机生成。
- 整行填满自动消除并计分：消 1/2/3/4 行分别得 100/300/500/800 分。
- 方块堆积到顶部时游戏结束，显示最终得分与消除行数。

## 四、核心实现

| 模块 | 函数 | 作用 |
|------|------|------|
| 方块旋转 | `rotate()` | 4×4 矩阵顺时针旋转 90° |
| 碰撞检测 | `collide()` | 判断是否越界或与已固定方块重叠 |
| 方块生成 | `spawn()` | 随机生成新方块并重置位置 |
| 方块锁定 | `lockPiece()` | 方块落底后写入棋盘 |
| 消行计分 | `clearLines()` | 消除满行并按数量计分 |
| 画面绘制 | `draw()` | 清屏并重绘棋盘、得分信息 |
